# Text-Analysis-App
Text Analysis App originally designed for a university project. Analyzes text files to determine similarity of 2 different files, as well as metrics of singular files.


Requires:
2 text files to analyze
A stopwords file, must be in source directory and named stopwords.txt
A positive sentiment file, must be in source directory and named positive.txt
A negative sentiment file, must be in source directory and named negative.txt

All files can be empty, but must be present
